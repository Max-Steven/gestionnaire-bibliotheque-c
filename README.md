

GESTIONNAIRE DE LIVRES DANS UNE BIBLIOTHÈQUE


Ce projet est une application de langage C permettant de gérer les activités d'une biliothèque à travers une interface en ligne de commande.



FONCTIONNALITÉS
- Gestion de livres (ajout, recherche, modification, suppression)
- Gestion de clients (ajout, recherche, modification, suppression)
- Gestion des emprunts (ajout, recherche, suppression)
- Sauvegarde des données


TECHNOLOGIES UTILISÉES
- Langage C
- GCC
- Fichiers binaires pour le stockage des données

INSTALLATION ET EXÉCUTION (TERMINAL)
- Compilation : gcc *.c -o library
- Exécution : ./library

INFORMATIONS ET RECOMMANDATIONS
- La limite des livres, des clients et des emprunts que l'on peut enregistrer est de 100
- Il est interdit de mettre des identifiants égaux à zéro
- L'identifiant d'un emprunt est généré automatiquement
- Pour entrer le numéro de téléphone d'un client, vous devez ajouter l'indicatif du pays commençant par 00 (Ex : 00229**********)
